# Changelog

All notable changes to the native Spicetify extension are recorded here. Dates are omitted until a public release is made.

## Unreleased

- Added a native Spicetify extension entry point with direct Player controls and no Electron or local HTTP bridge.
- Restored the compact artwork-and-lyric pill and expanded vertical player layout based on the original project.
- Added line-synchronized Vertical Wipe, wrapped lyric lines, track-information fallback, progress display, vinyl artwork, and adaptive album color.
- Added English Marketplace and contributor documentation.

- Rebranded Lyric Island to Popliyric, added a custom waveform top-bar icon, and refreshed the Marketplace preview and metadata without changing player behavior.
